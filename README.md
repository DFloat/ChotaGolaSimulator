# GolaGolaSimulator
어마 무시하게, 진쩌 훨씬 더, 개미의 유전자 조직 구조보다도 쓸모없는 무언가입니다.
기존 유니티는 포크하기가 좀 까다로웠어서, 가장 편집이 쉬운 HTML로 포크했습니다
무엇보다 유니티 to HTML은 100% 바꾸기가 엄청나게 어렵기에, 에이전트를 통해 코딩을 짰습니다
그래서 목적 자체는 더 접근 쉬운 골라골라를 만들기였습니다

## 원본과의 변경사항
1. 폰트를 찾기가 힘들었습니다. 가장 유사해 보이던 제주고딕으로 대체했습니다.
2. 일부 로직 자체가 구현이 안 되었을 수도 있습니다.
3. 왼쪽 위 알림의 Ui와 Tab를 눌러서 옵션을 킬때, 옵션의 Ui가 원본과 상당히 다릅니다. (유니티 자체의 UI 엔진인것으로 추정합니다, HTML에서 구현하기 빡셀 것 같아서 에이전트 채찍을 멈췄습니다.)

## 알려진 버그
1. 애피 슬라이드의 렌더링 문제 : 어쩔 수 없더라고요. 조금씩 렌더링이 끊김.
2. 애피 슬라이드 진입시 자동으로 배경이 하늘색으로 바뀌지 않음 : 귀찮아서 패치를 안했음
